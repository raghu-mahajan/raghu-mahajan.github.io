Open Problems in String Theory

A public list of string theory problems that people would like to see solved. Anyone is welcome to add one.

This list was created by the participants of the ICTS Worldsheet String Theory and String Field Theory Workshop in November 2026.

If you work on one of these problems

Anyone who tackles a problem from this list is expected to contact the person who posted it if they make progress. We can't enforce this, but it is the right thing to do.

Add a problem
